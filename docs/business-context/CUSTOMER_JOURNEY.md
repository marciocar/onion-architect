## 🟢 Estágio 3: Onboarding

### Primeiros Marcos de Sucesso
O que precisa acontecer para o cliente se sentir bem-sucedido?

| Marco | Tempo | Ação | Emoção Esperada |
|-------|-------|------|-----------------|
| **Signup completo** | 0-2 min | Criar conta (Logto) | 😊 "Fácil!" |
| **Primeiro contato com @onion** | 2-5 min | Interação guiada | 🤔 "Interessante" |
| **Primeira knowbase criada** | 5-10 min | Upload ou criação | 😃 "Estou organizando!" |
| **Primeira pergunta respondida** | 10-15 min | Perguntar sobre knowbase | 🤩 "Funciona!" |
| **Primeiro agente criado** | 15-30 min | Criar agente personalizado | 🎉 "Tenho meu assistente!" |

### Pontos de Confusão Comuns
Onde novos usuários geralmente travam?

| Ponto | Problema | Solução |
|-------|----------|---------|
| "O que é uma knowbase?" | Terminologia nova | Tooltips + exemplos visuais |
| "Como criar um agente?" | Processo não intuitivo | Wizard guiado + templates |
| "Para que servem regras?" | Conceito abstrato | Casos de uso concretos |
| "Como o @onion me ajuda?" | Não sabe começar | Sugestões proativas |

### Padrões de Adoção
Como clientes de sucesso geralmente usam o produto?

**Semana 1:**
- Criar 1-2 knowbases com conhecimento essencial
- Fazer 10-20 perguntas para testar
- Configurar primeiro agente básico

**Semana 2-4:**
- Expandir knowbases com conteúdo do dia-a-dia
- Criar 2-3 comandos para tarefas recorrentes
- Explorar integrações básicas

**Mês 2+:**
- Knowbases como parte do workflow diário
- Agentes especializados para diferentes contextos
- Automações com scheduler

## 🔴 Estágio 4: Crescimento (Growth)

### Oportunidades de Expansão
Como clientes aumentam o uso?

| Gatilho | Expansão | Indicador |
|---------|----------|-----------|
| "Preciso de mais espaço" | Upgrade de storage | Limite de upload atingido |
| "Quero recursos avançados" | Upgrade de plano | Uso de features premium |
| "Meu time quer usar" | Adicionar seats | Convites para colegas |
| "Preciso de mais automações" | Mais créditos de execução | Scheduler no limite |

### Casos de Uso Avançados
O que power users desenvolvem?

1. **Assistente de pesquisa pessoal**
   - Knowbases de artigos e papers
   - Agente que resume e conecta ideias
   - Comando para gerar insights

2. **Sistema de onboarding pessoal**
   - Knowbase de processos e SOPs
   - Agente que responde dúvidas
   - Regras de formatação

3. **Automação de conteúdo**
   - Knowbase de referências e estilo
   - Agente que gera drafts
   - Scheduler para publicação

4. **CRM pessoal**
   - Knowbase de contatos e interações
   - Agente que lembra follow-ups
   - Comandos de preparação para reuniões

### Indicadores de Sucesso
Comportamentos que indicam cliente saudável:

| Métrica | Saudável | Em risco |
|---------|----------|----------|
| **Logins/semana** | 3+ | < 1 |
| **Perguntas/semana** | 10+ | < 3 |
| **Knowbases ativas** | 3+ | 1 |
| **Agentes criados** | 2+ | 0 |
| **Comandos usados** | 5+ | 0 |

## ⚠️ Estágio 5: Retenção vs Churn

### Indicadores de Risco de Churn

| Sinal | Urgência | Ação |
|-------|----------|------|
| 7 dias sem login | 🟡 Média | Email de re-engajamento |
| 14 dias sem login | 🔴 Alta | Oferta de ajuda personalizada |
| Downgrade de plano | 🔴 Alta | Pesquisa de satisfação |
| Reclamação de suporte | 🟡 Média | Follow-up proativo |
| Exportação de dados | 🔴 Crítica | Conversa 1:1 |

### Motivos Comuns de Churn

| Motivo | Frequência | Prevenção |
|--------|------------|-----------|
| "Não tive tempo de configurar" | 🔴 Alta | Onboarding mais simples |
| "Não vi valor suficiente" | 🔴 Alta | Time-to-value mais rápido |
| "Muito caro para o que uso" | 🟡 Média | Planos flexíveis |
| "Ferramenta X faz mais" | 🟡 Média | Diferenciação clara |
| "Minha situação mudou" | 🟢 Baixa | Pausar conta |

### Estratégias de Recuperação

1. **Re-engajamento por email**
   - "Seu @onion sente sua falta"
   - Mostrar novos recursos
   - Oferecer sessão de ajuda

2. **In-app prompts**
   - "Que tal criar um agente para [caso de uso]?"
   - Sugestões baseadas em padrões de uso

3. **Ofertas especiais**
   - Desconto para retorno
   - Upgrade temporário gratuito

4. **Exit survey**
   - Entender motivo real
   - Oferecer alternativas

### Drivers de Renovação
O que motiva clientes a continuar/expandir?

| Driver | Impacto | Como medir |
|--------|---------|------------|
| **Valor diário percebido** | 🔴 Alto | NPS, usage frequency |
| **Custo de troca** | 🟡 Médio | Dados acumulados |
| **Novas features** | 🟡 Médio | Feature adoption |
| **Comunidade** | 🟢 Baixo | Community engagement |

## 🎯 Implicações para o Produto

### Prioridades de Desenvolvimento

1. **Reduzir tempo até primeiro valor** (< 5 min)
2. **Simplificar conceitos** (knowbase, agente, comando)
3. **Criar templates prontos** para casos de uso comuns
4. **Implementar nudges** em momentos de risco
5. **Construir programa de referral** desde V1

### Triggers Automáticos

| Evento | Ação | Canal |
|--------|------|-------|
| Signup | Welcome + primeiro passo | In-app + email |
| 24h sem ação | "Que tal criar sua primeira knowbase?" | In-app |
| Primeira pergunta | "Parabéns! Veja o que mais pode fazer" | In-app |
| 7 dias inativo | Re-engajamento | Email |
| Primeiro agente | "Você é um Onion Pro! Próximo passo..." | In-app |
