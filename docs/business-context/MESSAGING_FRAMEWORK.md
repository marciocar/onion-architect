## ❌ Topics to Avoid

### Nunca Dizer

| Evitar | Por quê | Usar |
|--------|---------|------|
| "Powered by GPT-4" | Foco no resultado, não na tech | "IA avançada" |
| "Machine learning" | Jargão técnico | "Aprende com você" |
| "Enterprise-grade" | Genérico, sem significado | Especificar: "99.9% uptime" |
| "Revolutionary" | Hype vazio | Mostrar resultados |
| "Best AI platform" | Não-comprovável | "Economize 5h/semana" |

### Nunca Prometer

| Não prometer | Por quê |
|--------------|---------|
| "100% preciso" | IA pode errar |
| "Substitui humanos" | Posicionamento é amplificar |
| "Funciona para tudo" | Foco em PKM + automação |
| "Resultados garantidos" | Depende do uso |

## ✅ Brand Voice Checklist

Antes de publicar qualquer conteúdo:

- [ ] É acessível para quem não é técnico?
- [ ] Foca em benefícios, não features?
- [ ] Tom é acolhedor e empoderador?
- [ ] Tem prova/evidência do claim?
- [ ] CTA é claro e acionável?
- [ ] Evita jargão técnico desnecessário?
- [ ] Celebra o usuário, não o produto?
- [ ] Consistente com brand voice?
